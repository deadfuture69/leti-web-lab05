# Лабораторная 05. Динамические страницы JSP

Нужны JDK 21, Maven 3.9 и Apache Tomcat 10.1. Из корня проекта выполните `mvn clean package`.
Скопируйте `target/lab05.war` в папку `webapps` Tomcat, запустите сервер и откройте [приложение](http://localhost:8080/lab05/).
Для просмотра таблицы откройте `movies.jsp?name=Маша`. При пустом параметре name выводится отдельная страница ошибки.
Для генерации документации Java выполните `mvn javadoc:javadoc`.

Начните с index.jsp. Форма передаёт имя в movies.jsp, пустое имя обрабатывается отдельной страницей ошибки.
